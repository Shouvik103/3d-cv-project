Original synthetic multiview scene generated by `code/data/make_sample.py --out sample_data/scene_small`. Eight 800x600 images, exact calibration and poses. This tests image-based reconstruction; it is not a real-world benchmark. No third-party images or weights.

`colmap/` contains the measured CPU COLMAP baseline for these generated images, exported with pycolmap 4.2.1. `gt_poses.json` contains the exact renderer cameras used for ground-truth evaluation.

## Offline mesh demo

`scene.json` points at `reconstruction/`, copied from our actual SfM output for
these images. `depth_mono/` contains cached Depth Anything V2 Small inverse-depth
predictions for the default five fusion images; three held-out images are not
used for depth/fusion. The checkpoint revision, input settings and image hash
are in each cache. The PLY/GLB light meshes are measured outputs of this pipeline,
not ground-truth surfaces. No model weights are distributed.

Run from the repository root:

```
python code/mesh/run_mesh.py --scene sample_data/scene_small --out outputs/mesh --cache-only
python code/viz/view_mesh.py --mesh sample_data/scene_small/mesh_light.glb
```

Changing inference settings or the view split can require additional predictions;
use the existing matching settings for a completely offline run.
