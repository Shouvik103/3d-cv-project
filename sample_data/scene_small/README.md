Original synthetic multiview scene generated by `code/data/make_sample.py --out sample_data/scene_small`. Eight 800x600 images, exact calibration and poses. This tests image-based reconstruction; it is not a real-world benchmark. No third-party images or weights.

`colmap/` contains a measured CPU COLMAP reconstruction of these generated images, exported with pycolmap 4.2.1. It is a baseline output, not ground truth. `gt_poses.json` contains the actual renderer cameras. VGGT output is not included because GPU inference has not been run.
