# Offline analytic mesh fixture

Original 80x80 sphere images, exact synthetic camera poses and sparse landmarks,
and cached analytic inverse depth. This is a numerical/portability fixture, not
a Depth Anything prediction or evidence of real-world quality.

Run `python code/mesh/run_mesh.py --scene sample_data/mesh_sphere --out outputs/mesh_sphere --config configs/mesh_sample.yaml`. The cache needs no model download.
